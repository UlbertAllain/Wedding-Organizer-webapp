# Dribbble-inspired direction

This interface does not reproduce a single Dribbble shot. It combines reusable design principles from several references into an original system for the Wedding Organizer application.

## Selected references

1. **Wedora — Luxury Wedding Planner Website Design**
   - Sage and cream palette
   - Arched editorial imagery
   - Strong contrast between calm light surfaces and dark green sections

2. **Wedding Event Planner Service Website — Wonklab**
   - Large editorial typography
   - Visual storytelling and generous spacing
   - Clear service hierarchy and naturally placed calls to action

3. **Wedding Planner Website — UI Design Exploration**
   - Alternating story sections
   - Restrained neutral palette
   - Photography as the primary emotional element

4. **Wedding Planner Dashboard — tonik**
   - Collaboration-oriented workspace
   - Operational information presented before decorative metrics
   - Soft neutral foundation with clear active states

## Implemented system

- Warm paper background, deep forest primary, clay accent, restrained sage support.
- Only one ornamental motif: arched photography.
- Navigation uses numbered labels instead of decorative icons.
- Dashboard prioritizes the nearest event, pending decisions, payments, and recent bookings.
- No fake progress percentages or technical infrastructure copy in the user interface.
- Consistent square controls and minimal radius; rounded shapes are reserved for portraits and editorial photo arches.
